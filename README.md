# Savanna Grill Restaurant Website

## Project Overview

Savanna Grill is a responsive multi-page restaurant website created for a fictional Kenyan restaurant located in Kilimani, Nairobi.

The restaurant focuses on Kenyan-inspired dishes presented with a modern dining experience, including nyama choma, grilled tilapia, Kenyan coffee, cocktails, and other locally inspired meals.

The project was built to demonstrate practical understanding of HTML5, CSS3, Flexbox, CSS Grid, responsive web design, multi-page navigation, image handling, forms, and website deployment.

## Project Objectives

The main objectives of this project are to:

- Build a complete multi-page restaurant website.
- Use semantic HTML5 structure.
- Create consistent navigation across all pages.
- Apply CSS styling using Flexbox and Grid.
- Build responsive layouts for mobile, tablet, and desktop.
- Display restaurant menu items clearly.
- Create reusable card layouts.
- Include a restaurant image gallery.
- Build an accessible contact form.
- Embed a Google Map.
- Apply hover effects and simple CSS animations.
- Deploy the completed website using GitHub Pages.

## Website Pages

The website contains four main pages.

### 1. Home Page — `index.html`

The Home page introduces the Savanna Grill restaurant and contains:

- Navigation bar
- Hero section
- Restaurant name
- Tagline
- View Menu button
- Featured dishes
- Why Choose Us section
- Restaurant image gallery
- Special offer content
- Call-to-action section
- Footer

The main tagline is:

> Where Kenyan Flavours Meet Modern Craft

---

### 2. Menu Page — `menu.html`

The Menu page displays the restaurant's food and drink options.

Menu categories include:

- Breakfast
- Lunch
- Dinner
- Drinks

Each menu item contains:

- Dish name
- Description
- Price in Kenyan Shillings (KES)

Examples include:

- Nyama Choma Platter
- Grilled Tilapia
- Savanna Burger
- Chicken Biryani
- Githeri Bowl
- Coconut Prawn Curry
- Kenyan Coffee
- Dawa Cocktail

---

### 3. About Page — `about.html`

The About page provides information about the restaurant and its background.

It contains:

- Our Story banner
- Restaurant history
- Restaurant philosophy and values
- Local ingredient sourcing information
- Meet the Team section

Team members include:

- Chef Amani Odera — Head Chef & Founder
- Wanjiku Mwangi — Restaurant Manager
- Brian Kipchoge — Sous Chef

---

### 4. Contact Page — `contact.html`

The Contact page allows customers to find and contact the restaurant.

It contains:
